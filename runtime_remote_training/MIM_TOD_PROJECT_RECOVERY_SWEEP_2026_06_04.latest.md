# MIM/TOD Project Recovery Sweep - 2026-06-04

Status: completed_with_evidence

## Trigger
Dave asked MIM/Codex to go through every Studio project, ask for status/blockers/next steps/evidence needed, address drift, and update the Projects page without further Dave intervention.

## Failure Found
The first sweep prompt included: "what needs to be done to complete?"

MIM's project completion detector treated the word "complete" as operator acceptance and falsely marked 31 projects completed.

## Repair
- Tightened completion intent detection so questions about what remains, what is needed, what must happen, or how to complete do not close projects.
- Kept explicit closeout language working, such as "we can close this one as success and complete."
- Removed 31 false `operator_completed` events generated by the audit sweep.
- Restored 31 project rows into realistic states.
- Reclassified long-running umbrellas as ongoing programs.
- Preserved only two true completed projects:
  - LAB Workbench Servo Tester.
  - Studio Projects Table Organization.
- Restored specific project next actions where reconciliation had flattened them into generic blocker repair.

## Policy Lesson
Questions about completion are not completion approval.

MIM/TOD may close a project only when operator language clearly accepts completion or when evidence satisfies acceptance criteria through an approved closeout path.
