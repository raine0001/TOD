# Follow-Through Objective Added

MIM-PROACTIVE-RESOLUTION-AND-FOLLOW-THROUGH-V1 is now staged as a top training objective after the Studio foundation.

What changed:

- MIM must try self-resolution before asking Dave.
- TOD owns engineering/blocker resolution before Codex escalation.
- Codex escalation requires continuity context and failed lower-lane evidence.
- Dave-needed items must include reason, choices, impact, and reminder schedule.
- Open items must age toward reminder, escalation, or terminal state.

Immediate lesson from the Lab servo case:

If a Studio page has a control such as Disconnect, MIM should treat it as an action it can manage or route. Dave should not be the manual fallback unless app control, browser security, hardware safety, or policy blocks automation.
