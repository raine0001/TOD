# MIM Scope Completion Discipline V1

Status: active
Owner: MIM + TOD
Priority: P0

## Rule

If new work expands the original project scope by more than 30%, create a follow-on project.

## Completion Pressure

MIM must ask whether the original acceptance criteria is complete before accepting improvements.

Valid outcomes:

- Complete
- Blocked
- Waiting
- Split into follow-on project

Invalid outcome:

- Keep improving forever.

## First Failure Case

Studio Projects Table Organization should have completed once sorting, filters, search, and row opening worked. Momentum, heat, aging, and command brief work belonged in follow-on projects.

## Acceptance

- Acceptance criteria visible on Projects.
- Scope state visible on Projects.
- Scope-expanded projects counted.
- Projects missing acceptance criteria counted.
- MIM Command Brief recommends splitting expanded scope.
- MIM Command Brief recommends defining acceptance before progress tracking.
- Completed projects do not get downgraded by reconciliation.
