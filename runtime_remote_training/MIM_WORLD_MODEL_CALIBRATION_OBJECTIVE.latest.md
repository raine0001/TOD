# MIM-WORLD-MODEL-CALIBRATION-V1

Goal: teach MIM where things are before asking her to pick anything up.

Tomorrow starts with calibration, not gripping. MIM should use the saved safe exploration pose, table markers, hand camera, room camera, C12 distance, RPLIDAR, and joint poses to build a temporary workspace model.

Success means MIM can explain where the gripper, table references, and object candidates are relative to each other, and can predict small correction moves before contact.

Completion requires calibration evidence, not a block pickup.
