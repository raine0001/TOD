# Meshtastic Ship Mesh Setup Guide

## Overview
- **2 mesh radio nodes** on the ship provide group chat with NO internet needed
- **Node PA** (Port A) — forward area
- **Node SB** (Starboard B) — aft area
- Everyone connects via **Bluetooth** to the nearest node and shares the **primary channel**

---

## BEFORE BOARDING

### Install App
- **Android**: Google Play Store → search "Meshtastic" → install
- **iOS**: Apple App Store → search "Meshtastic" → install

### Enable Phone Settings
- Turn **Bluetooth ON**
- Turn **Location ON** (required for Meshtastic)
- **Android only**: Settings → Apps → Meshtastic → Battery → set to "No restrictions"

### Grant Permissions
- When app first opens, allow:
  - **Nearby devices** (or Bluetooth)
  - **Location**
  - **Notifications**

---

## CONNECTING TO A NODE

### Android
1. Open **Meshtastic** app
2. Tap **"Connect"** or **"Add Device"**
3. Select nearest node: **PA** or **SB**
4. Enter PIN: **2277**
5. Wait for **Connected** status at top of screen

### iOS
1. Open **Meshtastic** app
2. Tap the device icon or **"Select Device"**
3. Choose **PA** or **SB** from the list
4. Enter PIN: **2277**
5. Confirm **Connected** indicator appears

---

## SET YOUR DISPLAY NAME

1. Tap **Profile** or **Settings** (app varies)
2. Find **"Display Name"** or **"My name"**
3. Enter: **FirstName-Initial** (example: Sam-R or Mia-K)
4. **Do NOT change node names** (PA or SB)

---

## SEND A MESSAGE

### Group Message (Everyone on the ship)
1. From home screen, tap **"Primary"** channel or **"SHIP-GROUP"**
2. Type your message
3. Tap **Send**
4. Everyone on both nodes receives it

### Private Message (One person only)
1. Tap the **Chat** or **Contacts** tab
2. Find the person's name or the node (PA / SB)
3. Tap to open direct chat
4. Type message
5. Tap **Send**

## IF YOU GET "NOT CONNECTED"

**Try this (about 45 seconds):**
1. Keep app in foreground
2. **Toggle Bluetooth off, wait 3 seconds, turn back on**
3. Tap **Reconnect** or **"Connect"** in app
4. Re-enter PIN: **2277**
5. If still failing, try the **other node** (PA or SB)

**If both nodes fail:**
- Contact the **radio admin** — ask them to check node status
- Use the **fallback Wi-Fi** method if directed

---

## MESSAGE BEST PRACTICES

- Keep messages **short and clear**
- Start with your **role/location** if useful:
  - Example: "BRIDGE: Need tools at aft deck"
- Use **group chat** for general announcements
- Use **direct message** only for private/urgent traffic
- Don't rename nodes unless you're the **admin**

---

## QUICK TROUBLESHOOT TABLE

| Problem | Fix |
|---|---|
| App says "Not Connected" | Toggle Bluetooth off/on, reconnect to PA or SB, re-enter PIN |
| Can't find PA or SB | Ensure Bluetooth is ON and Location is ON |
| Another person can't connect | Ask admin if that node is at max users; try the other node |
| Messages not arriving | Confirm both sender and receiver are on same primary channel |
| Forgot PIN | PIN is **2277** |

- ✅ Both nodes on channel: **SHIP-GROUP**
- ✅ Both nodes Bluetooth PIN: **2277**
- ✅ All crew installed app and set display names
- ✅ Quick test: admin sends one message, crew confirms receipt
